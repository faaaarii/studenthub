# StudentHub

- a web application for managing a list of students.

## Features

- Display list of students
- Add a student through a form
- Validate required fields and reasonable values (name has no numbers and age must be between 16 and 30)
- Search students by name
- Filter by course
- Delete a student
- Responsive layout for desktop and smaller screens


## Built with

- HTML, CSS, JS, GoogleFont

## Requirements

- A web browser
- Git

## How to run

1. Clone the repository:
   ```
   git clone https://github.com/faaaarii/studenthub.git
   ```
2. Open the `studenthub` folder.
3. Double-click `studentlist.html` to open it in your web browser.

**Optional:** In VS Code, install the **Live Server** extension, right-click `studentlist.html`, and choose **Open with Live Server**.

## Notes
- **Phone view:** in Chrome, press `F12`, then `Ctrl + Shift + M`.
- Data is stored in memory, so the added and deleted student information will be reset if the page is refreshed.
